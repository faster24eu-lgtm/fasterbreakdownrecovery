# Image assets

No stock or placeholder photography has been added — the current design is
built with CSS and inline SVG icons so the site launches without needing any
photos. Add genuine business photography into the folders below as it
becomes available; each `<img>` can then be added where noted in the HTML.

- `logo/` — brand logo files (SVG preferred, plus a PNG fallback if needed).
- `hero/` — homepage and page-header photography (recovery truck in
  operation, loading a vehicle, etc). Recommended: 1920x1080, WebP + JPG.
- `gallery/` — fleet, equipment and "in action" photos for the About and
  service pages. Recommended: 1200x800, WebP + JPG.
- `og/` — Open Graph / social share image. Replace `og-image-placeholder.svg`
  with a real 1200x630 JPG or PNG before launch — most social platforms do
  not render SVG previews.
- `icons/` — favicon and UI icon source files.

## Naming convention

Use descriptive, hyphenated, lowercase file names that describe the real
content, e.g. `recovery-truck-loading-hatchback.jpg`,
`flatbed-a90-roadside.jpg`. Avoid generic names like `IMG_1234.jpg`.

## Alt text

Write alt text that describes what is genuinely in the photo (e.g. "Faster
Breakdown Recovery flatbed truck loading a car on the A90 near Aberdeen") —
do not reuse the same alt text across multiple images.
